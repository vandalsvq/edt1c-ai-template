# Сценарий 1. Форма по описанию задачи

Прогон скилла `form-mockup` (02.11.2026). Модель - `zayavka-na-zakupku.json`,
снимки и HTML - `python3 tools/form-mockup/formmockup.py render tools/form-mockup/examples/scenarios/1-po-opisaniyu/zayavka-na-zakupku.json -o tools/form-mockup/examples/scenarios/1-po-opisaniyu/out --png`.

**Задача.** Документ «Заявка на закупку»: сотрудник подразделения заказывает товары. Шапка -
номер, дата, организация, подразделение, ответственный, желаемая дата поставки,
предполагаемый поставщик (необязательно), статус (Черновик, На согласовании, Согласована,
Отклонена) - статус только для просмотра. Табличная часть «Товары»: номенклатура,
характеристика, количество, единица измерения, ориентировочная цена, сумма, назначение.
Итог суммы по заявке. На отдельной закладке - история согласования: дата, согласующий,
решение, комментарий, только просмотр. Команды: «Отправить на согласование», печать «Заявка
на закупку». Комментарий к документу.
