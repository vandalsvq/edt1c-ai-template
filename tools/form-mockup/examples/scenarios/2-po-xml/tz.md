# Сценарий 2. Форма по XML

Прогон скилла `form-mockup` на форме элемента справочника `_ДемоДоговоры` из фикстур тестов
инструмента.

```text
python3 tools/form-mockup/formmockup.py import tools/form-mockup/tests/fixtures/import/edt/Catalogs/_ДемоДоговоры/Forms/ФормаЭлемента/Form.form -o tools/form-mockup/examples/scenarios/2-po-xml/dogovor.json
python3 tools/form-mockup/formmockup.py render tools/form-mockup/examples/scenarios/2-po-xml/dogovor.json -o tools/form-mockup/examples/scenarios/2-po-xml/out --png
```

«Записать».
