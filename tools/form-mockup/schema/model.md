# Модель формы: справочник видов и свойств

Модель - JSON-дерево элементов управляемой формы 1С: по ней рендерер рисует форму, по ней
`formmockup.py check` проверяет состав, по двум её версиям строятся правки. Имена видов и
свойств - как в платформе (camelCase, как в XML формы EDT); русское название каждого имени -
в `dictionary-ru.json`, быстрый перевод - `formmockup.py ru <слово>`. Схема -
`form-model.schema.json`.

Принципы:

- **Дерево, а не координаты.** Расположение задают группы (направление, отображение,
  растягивание), как в конфигураторе; пиксели считает рендерер.
- **Размеры - в единицах 1С:** `width` - в символах, `height` - в строках. Не указано - как
  у платформы по умолчанию.
- **Не указано - значит по умолчанию платформы.** В модель пишется только то, что отличается
  от умолчания: `visible`, `enabled` по умолчанию истина, `titleLocation` - `Auto`.
- **`name` уникально по всей форме**, включая кнопки командных панелей: по нему сравниваются
  версии формы и строится таблица для ТЗ.
- **Свойство модели - свойство платформы с тем же именем**, кроме перечисленных в разделе
  «Свойства вне платформы»: у них пометка «нет в 1С» или «в 1С не напрямую» с пояснением.

## Корень

```json
{ "version": 1, "form": { "title": "...", "formKind": "DocumentObjectForm", "items": [ ... ] } }
```

| Свойство | Русское | Значение |
| --- | --- | --- |
| `version` | Версия модели | всегда `1`; *нет в 1С* |
| `form` | Форма | объект вида `Form` (свойство `type` у формы не пишется); *в 1С не напрямую* |
| `tags` | Метки | массив строк: задача, назначение, состояние (`Задача-12`, `ТЗ`); стартовая страница сервиса фильтрует и ищет по ним, форму не меняют; *нет в 1С* |
| `origin` | Откуда взят | `{kind, ...}`: `config` - форма исходников (`object` - ключ формы, `project` - проект), `file` - перетащенный файл (`name`), `copy` - копия макета (`from` - путь оригинала, `folder` - папка оригинала, если другая); `at` - дата и время. Пишут импорт и копирование, задел для обновления по исходнику; *нет в 1С* |
| `attributes` | Реквизиты | реквизиты формы - раздел «Реквизиты формы» ниже |
| `types` | Типы макета | состав объектных и ссылочных типов для дерева пути к данным - там же; *нет в 1С* |
| `commands` | Команды | команды формы - раздел «Команды формы» ниже |
| `styles` | Цвета стиля макета | словарь: имя элемента стиля (`FormTextColor`, `ГиперссылкаЦвет`) → `#RRGGBB`, значение цвета `style:<Имя>` для рисования. Только цвета, на которые ссылается форма. Заполняет импорт: элементы стиля конфигурации из исходников (с поправкой основного стиля конфигурации) и цвета стиля платформы (основной стиль или таблица «Такси» инструмента `schema/colors-1c.json`); конструктор - при выборе цвета стиля (все элементы стиля конфигурации окно цвета берет у сервера при `serve --src`). Элемента нет в словаре - рисуется без цвета, `check` замечает; *нет в 1С* |
| `pictures` | Картинки макета | словарь: имя картинки элементов (`CommonPicture.Имя`, `StdPicture.Имя`) → data URI (`data:image/png;base64,...`). Заполняет импорт: общие - из исходников конфигурации (вариант «Такси», 100 %), стандартные - из выгрузки платформы (архив инструмента `std-pictures.zip` или своя выгрузка `1c/ВыгрузитьСтандартныеКартинки.bsl`, параметр `--std-pictures`), в том числе картинки кнопок полей и таблиц; картинки нет в словаре - стандартная рисуется значком макета, прочие - заглушкой; *нет в 1С* |

## Где что лежит

| Контейнер | Допустимые дети (`items`) |
| --- | --- |
| `Form`, `UsualGroup`, `Page` | `UsualGroup`, `Pages`, `InputField`, `CheckBoxField`, `RadioButtonField`, `LabelField`, `Table`, `LabelDecoration`, `PictureDecoration`, `CommandBar`, `Button`, `Popup`, поля-заглушки, `Unknown` |
| `Pages` | только `Page` |
| `Table`, `ColumnGroup` | колонки: `InputField`, `CheckBoxField`, `LabelField`, `ColumnGroup`, поля-заглушки, `Unknown` |
| `AutoCommandBar`, `CommandBar`, `ButtonGroup`, `Popup` | `Button`, `ButtonGroup`, `Popup`, `Unknown` |

Командная панель формы и таблицы - не элемент `items`, а свойство `commandBar` вида
`AutoCommandBar`.

## Свойства вне платформы

Реестр - ключ `x-platform` в корне схемы; оттуда же пометка в выводе `formmockup.py ru`.
Новое свойство без пары в платформе вносится в реестр тем же изменением, что и в схему.

**Нет в 1С** - только модель, в форму не переносится:

| Свойство | Пояснение |
| --- | --- |
| `version` | версия формата файла модели |
| `note` | примечание для ТЗ |
| `sample` | пример значения для картинки; в 1С значение приходит из данных |
| `renamedFrom` | прежнее имя для сравнения версий формы; в 1С - переименование элемента |
| `sourceType` | вид элемента в исходном XML, который импорт не распознал (вид `Unknown`) |
| `pictures` | данные картинок для рисования макета; в 1С - общие картинки конфигурации |
| `styles` | значения цветов стиля для рисования макета; в 1С - элементы стиля конфигурации и стиль платформы |
| `types` | состав объектных и ссылочных типов для дерева пути к данным; в 1С - объекты метаданных конфигурации |

**В 1С не напрямую** - есть в 1С, но под другим именем или другим способом:

| Свойство | Как переносится |
| --- | --- |
| `form` | сама форма (ФормаКлиентскогоПриложения), корень дерева модели |
| `type` | тип объекта платформы и его свойство Вид: `InputField` - ПолеФормы вида ПолеВвода, `UsualGroup` - ГруппаФормы вида ОбычнаяГруппа; `LabelDecoration`, `PictureDecoration`, `AutoCommandBar`, `Addition` - имена из XML формы EDT |
| `items` | свойство ПодчиненныеЭлементы (ChildItems); имя - как в XML формы EDT |
| `formKind` | роль формы у объекта метаданных; задается в свойствах объекта, а не формы |
| `dataType` | упрощенный тип для картинки; в 1С - тип реквизита формы (ОписаниеТипов) |
| `length` | длина строки из типа реквизита (КвалификаторыСтроки.Длина), 0 - неограниченная; у ссылки, представленной кодом, - длина кода объекта |
| `digits` | разрядность числа из типа реквизита (КвалификаторыЧисла.Разрядность) |
| `fractionDigits` | разрядность дробной части числа из типа реквизита (КвалификаторыЧисла.РазрядностьДробнойЧасти) |
| `enumValues` | значения перечисления из типа реквизита (синонимы); в 1С - состав перечисления в метаданных |
| `collapsed` | свойство конфигуратора; в коде - методы `Скрыта()`, `Показать()`, `Скрыть()` |
| `formatted` | в 1С - заголовок надписи типа ФорматированнаяСтрока |
| `buttonType` | свойство Вид кнопки (ВидКнопкиФормы); имя `type` в модели занято видом элемента |
| `additionType` | вид дополнения таблицы (в XML формы EDT - свойство `type`); имя `type` в модели занято видом элемента |
| `excludedCommands` | стандартные команды таблицы или формы, снятые в «Составе команд» (в XML формы EDT - `excludedCommands`); в 1С - флажки на закладке «Команды» редактора формы |
| `dateFractions` | состав даты из типа реквизита (КвалификаторыДаты.ЧастиДаты): дата, время, дата и время; не указан - дата и время, как в EDT |
| `main` | признак основного реквизита формы (в конфигураторе - ОсновнойРеквизит) |
| `help` | у формы или ее объекта есть справка (в конфигураторе - Справочная информация): в командной панели формы кнопка «?» |

## Общие свойства элементов

Есть у всех видов, кроме `Form`.

| Свойство | Русское | Тип | Смысл |
| --- | --- | --- | --- |
| `type` | Вид элемента | строка | вид из разделов ниже; обязательно; *в 1С не напрямую* |
| `name` | Имя | имя 1С | уникальное имя, как в конфигураторе; обязательно |
| `title` | Заголовок | строка | не указан - как платформа: у элемента с `dataPath` - заголовок реквизита по пути из `attributes` / `types`, иначе последнее имя пути по словам (стандартный реквизит - русским заголовком); без пути - `name` по словам; у кнопки команды формы - заголовок команды. Так же `table`, сравнение правок и серый заголовок в панели конструктора |
| `toolTip` | Подсказка | строка | |
| `extendedTooltip` | Расширенная подсказка | строка | текст расширенной подсказки (в 1С - заголовок надписи-подсказки элемента); при `formatted` - без разметки |
| `extendedTooltipTextColor` | Цвет текста расширенной подсказки | цвет | в 1С - цвет текста надписи-подсказки; не задан - серый текст подсказки |
| `toolTipRepresentation` | Отображение подсказки | `Auto`, `None`, `Balloon`, `Button`, `ShowAuto`, `ShowTop`, `ShowBottom`, `ShowLeft`, `ShowRight` | `Button` - «?» после элемента; `Show*` - текст подсказки рядом с элементом; прочее не рисуется |
| `visible` | Видимость | булево | `false` - рисуется только по переключателю «Показать скрытые» |
| `userVisible` | Видимость пользователя | булево | `false` - в 1С скрыт, пока пользователь не включит его в «Изменить форму» (конфигуратор показывает); рисуется с синей пунктирной рамкой, переключатель «Показать скрытые пользователем» убирает |
| `enabled` | Доступность | булево | `false` - элемент бледный |
| `width` | Ширина | целое ≥ 0 | в символах |
| `height` | Высота | целое ≥ 0 | в строках |
| `horizontalStretch` | Растягивать по горизонтали | булево | |
| `verticalStretch` | Растягивать по вертикали | булево | у надписи `horizontalStretch: true` - распорка: забирает остаток строки; многострочное поле ввода с `verticalStretch: true` делит остаток высоты окна, не ниже своей высоты |
| `groupHorizontalAlign` | Горизонтальное положение в группе | `Auto`, `Left`, `Center`, `Right` | `Right` прижимает элемент к правому краю группы |
| `groupVerticalAlign` | Вертикальное положение в группе | `Auto`, `Top`, `Center`, `Bottom` | положение элемента по высоте строки группы |
| `note` | Примечание для ТЗ | строка | на основном снимке не рисуется; попадает в колонку «Комментарий» таблицы элементов с номером в колонке «№» - тем же, что в кружке на снимке `<имя>__примечания.png` и на макете конструктора (элементы с `note` по порядку обхода дерева: форма, командная панель, элементы). `"предложение"` - элемент, предложенный агентом, а не взятый из задачи; *нет в 1С* |
| `renamedFrom` | Прежнее имя | имя 1С | только во второй версии формы: элемент переименован, а не удалён и добавлен заново; *нет в 1С* |

У полей (`InputField`, `CheckBoxField`, `RadioButtonField`, `LabelField`, поля-заглушки) и
у `Table` есть ещё:

| Свойство | Русское | Тип | Смысл |
| --- | --- | --- | --- |
| `dataPath` | Путь к данным | строка | `Объект.Контрагент`, `Список.Дата` - для таблицы ТЗ и подсказки |
| `titleLocation` | Положение заголовка | перечисление | `Auto` (Авто), `None` (Нет), `Left` (Лево), `Top` (Верх), `Right` (Право), `Bottom` (Низ) |
| `titleHeight` | Высота заголовка | целое ≥ 0 | в строках: заголовок слева делится на столько строк примерно поровну, даже если помещается в одну («Назначение↵платежа» БП); перевод строки в `title` переносит и без нее |
| `titleTextColor` | Цвет текста заголовка | цвет | как `backColor` группы; цвет стиля фона (`style:FormBackColor`, `style:ButtonBackColor` - белый) - подпись занимает место, но не видна (прием БП) |
| `readOnly` | Только просмотр | булево | |

У поля-колонки таблицы (по месту; у `ColumnGroup` - первые три) ещё:

| Свойство | Русское | Тип | Смысл |
| --- | --- | --- | --- |
| `headerHorizontalAlign` | Горизонтальное положение в шапке | `Auto`, `Left`, `Center`, `Right` | заголовок колонки в шапке; `Auto` и `Left` рисуются слева, импорт пишет только `Center` и `Right` (`Left` EDT пишет у каждого поля) |
| `headerBackColor` | Цвет фона заголовка | цвет | фон ячейки шапки колонки |
| `showInFooter` | Отображать в подвале | булево | `false` - ячейка подвала колонки пустая |
| `footerPicture` | Картинка подвала | имя картинки | перед текстом подвала |
| `footerHorizontalAlign` | Горизонтальное положение в подвале | `Auto`, `Left`, `Center`, `Right` | текст подвала в ячейке; `Auto` в 1С у числа справа, макет рисует его слева, как в ранних версиях |
| `footerBackColor`, `footerTextColor` | Цвет фона подвала, Цвет текста подвала | цвет | ячейка подвала колонки |
| `footerFont` | Шрифт подвала | шрифт | как `font` у кнопки |
| `cellHyperlink` | Гиперссылка ячейки | булево | значение в ячейках - ссылкой |
| `autoCellHeight` | Автовысота ячейки | булево | длинное значение переносится по словам, строка выше |

## Форма

### `Form` - Форма

| Свойство | Русское | Значение |
| --- | --- | --- |
| `title` | Заголовок | заголовок окна |
| `autoTitle` | Автозаголовок | `true` - к заголовку добавляется представление объекта; на макете не рисуется |
| `formKind` | Вид формы | `DocumentObjectForm` (Форма документа), `CatalogObjectForm` (Форма элемента справочника), `ListForm` (Форма списка), `ChoiceForm` (Форма выбора), `DataProcessorForm` (Форма обработки). От вида зависят стандартные команды автопанели; *в 1С не напрямую* |
| `width`, `height` | Ширина, Высота | в символах и строках |
| `group` | Группировка | как у `UsualGroup`; не указана - `Vertical` |
| `commandBar` | Командная панель | `AutoCommandBar`; не указана - автозаполненная панель по `formKind` |
| `commandBarLocation` | Положение командной панели | `Auto` (Авто), `None` (Нет), `Top` (Верх), `Bottom` (Низ) |
| `help` | Справка | `true` - справка есть: в панели формы после «Еще» кнопка «?»; *в 1С не напрямую* |
| `showTitle` | Отображать заголовок | `false` - окно без строки заголовка (и без кнопок навигации и закрытия); по умолчанию `true` |
| `showCloseButton` | Отображать кнопку закрытия | `false` - без крестика в заголовке окна; по умолчанию `true` |
| `excludedCommands` | Состав команд | имена стандартных команд формы (`Write`, `Post`, `Reread`...), снятых в «Составе команд»: их нет на панели формы и в «Еще»; *в 1С не напрямую* |
| `note` | Примечание для ТЗ | *нет в 1С* |
| `items` | Подчиненные элементы | содержимое формы; *в 1С не напрямую* |

## Командные панели и кнопки

### `AutoCommandBar` - Автоматическая командная панель, `CommandBar` - Командная панель

`AutoCommandBar` - панель формы или таблицы (свойство `commandBar`); `CommandBar` - панель,
размещённая среди элементов формы.

| Свойство | Русское | Значение |
| --- | --- | --- |
| `autoFill` | Автозаполнение | `true` - кроме своих кнопок, стандартные команды по виду формы или таблицы |
| `horizontalAlign` | Горизонтальное положение | `Auto` (Авто), `Left` (Лево), `Center` (Центр), `Right` (Право) |
| `commandSource` | Источник команд | у `CommandBar`, `ButtonGroup`, `Popup`: `Form` (Форма), `Item.<Таблица>`, `FormCommandPanelGlobalCommands` и другие. Кнопки источника в модели - явными элементами; панель среди элементов с источником `Form` внутри - панель формы: справа «Еще» и «?» (при `help`) |
| `items` | Подчиненные элементы | `Button`, `ButtonGroup`, `Popup`; *в 1С не напрямую* |

Меню «Еще» панели таблицы и формы рендерер собирает, как 1С: при автозаполнении - стандартные команды
таблицы (по секциям: правка и поиск, перемещение, сортировка и вывод списка; с учетом флагов изменения
строк и `excludedCommands`) или формы объекта, затем элементы панели в ее порядке (группы кнопок - между
чертами, кнопки `InCommandBar` - только если не поместились), у формы в конце «Изменить форму...» и
«Справка». Группа кнопок с источником - таблицей заполняется тем же набором без уже размещенных команд.

### `Button` - Кнопка

| Свойство | Русское | Значение |
| --- | --- | --- |
| `buttonType` | Вид кнопки | `UsualButton` (Обычная кнопка), `Hyperlink` (Гиперссылка), `CommandBarButton` (Кнопка командной панели), `CommandBarHyperlink` (Гиперссылка командной панели); не указан - кнопка; гиперссылка рисуется ссылкой без рамки; *в 1С не напрямую* |
| `commandName` | Имя команды | `Form.Command.Подобрать`, стандартная - `Form.StandardCommand.Write` |
| `picture` | Картинка | имя картинки: `StdPicture.Print` или своё (`CommonPicture.Имя` - из `pictures`); рисуется значком |
| `representation` | Отображение | `Auto` (Авто), `Text` (Текст), `Picture` (Картинка), `PictureAndText` (Картинка и текст). `Auto` с картинкой в командной панели - только картинка, у кнопки среди элементов - картинка и текст |
| `defaultButton` | Кнопка по умолчанию | выделенная кнопка формы |
| `check` | Пометка | `true` - кнопка нажата («вдавлена»), в меню - отметка у пункта; `false`, указанное явно, - кнопка с пометкой, не нажатая; не указано - обычная кнопка. Щелчок по кнопке с пометкой на макете нажимает и отжимает ее, как обработчик команды в 1С; это состояние просмотра, в модель не пишется. Импорт переносит только установленную пометку (в исходниках записана только она) |
| `locationInCommandBar` | Положение в командной панели | `Auto` (Авто) - на панели и в меню «Еще», `InCommandBar` (В командной панели) - только на панели, `InAdditionalSubmenu` (В дополнительном подменю) - только в «Еще». Импорт ставит `InAdditionalSubmenu` и стандартным командам, которые 1С при «Авто» держит в «Еще» («Изменить», «Удалить» строки таблицы, «Закончить редактирование», сортировка, поиск и т.п.) |
| `borderColor` | Цвет рамки | как `backColor` у группы |

| `font` | Шрифт | `faceName` (Имя шрифта) и `height` (Высота, размер в пунктах) - абсолютный шрифт; начертание: `bold` (Жирный), `italic` (Наклонный), `underline` (Подчеркнутый), `strikeout` (Зачеркнутый) - `true`. ### `ButtonGroup` - Группа кнопок

Кнопки, отделённые от соседних разделителем. Свойства - общие, `commandSource`, `items` и
`representation` - Отображение: `Auto` (Авто), `Usual` (Обычное), `Compact` (Компактное -
кнопки вплотную, без промежутка).

### `Addition` - Дополнение

Дополнение таблицы, вынесенное в командную панель (или форму): `additionType` - Вид дополнения
(*в 1С не напрямую*: в XML EDT свойство `type`): `SearchStringAddition` (Строка поиска - поле

### `Popup` - Подменю

Кнопка со стрелкой и выпадающим списком команд: `picture`, `representation` - как у
`Button`, `commandSource` - как у панели, `items` - пункты.

| `formatted` | Форматированная строка | `title` - форматированная строка в разметке 1С: `<b>жирный</>`, `<i>курсив</>`, `<link адрес>ссылка</>`; *в 1С не напрямую* |
| `hyperlink` | Гиперссылка | вся надпись - ссылка |

| --- | --- | --- |

## Команды формы

`commands` - команды формы: то, что в конфигураторе на закладке «Команды формы». Кнопка с командой
формы (`commandName: "Form.Command.<Имя>"`) без своего заголовка, картинки или отображения рисуется с ними из
команды; таблица `table` и правки видят у такой кнопки заголовок команды. Кнопка стандартной команды
(`Form.StandardCommand.Close`, `Form.Item.Товары.StandardCommand.Add`) без своего заголовка - заголовок платформы
(«Закрыть», «Добавить»), общей команды (`CommonCommand.Имя`) - имя команды по словам; смена команды в конструкторе
снимает заголовок, унаследованный от прежней команды. Импорт пишет все команды формы в
порядке XML, а в кнопку - только свое, отличное от команды; конструктор правит их в левой колонке («Команды»).

| Свойство | Русское | Значение |
| --- | --- | --- |
| `name` | Имя | имя команды; обязательно |
| `title` | Заголовок | не указан - имя по словам |
| `toolTip` | Подсказка | |
| `action` | Действие | имя обработчика в модуле формы; не рисуется |
| `picture` | Картинка | имя картинки, как у кнопки |
| `representation` | Отображение | `Auto`, `Text`, `Picture`, `PictureAndText` - как у кнопки |

## Реквизиты формы

`attributes` - реквизиты формы, `types` - состав их типов.
По ним конструктор строит дерево выбора пути к данным, `check` проверяет пути элементов. `render`, `table` и
`ru` их не показывают: макет рисует элементы.

```json
{ "version": 1, "form": { ... },
  "attributes": [
    { "name": "Объект", "valueType": "DocumentObject.ЗаказПокупателя", "main": true },
    { "name": "ИтогоСумма", "title": "Итого", "valueType": "Number", "digits": 15, "fractionDigits": 2 },
    { "name": "Подбор", "valueType": "ValueTable", "columns": [{ "name": "Номенклатура", "valueType": "CatalogRef.Номенклатура" }] },
    { "name": "Список", "valueType": "DynamicList", "mainTable": "Catalog.Номенклатура" }
  ],
  "types": {
    "Document.ЗаказПокупателя": {
      "title": "Заказ покупателя",
      "attributes": [{ "name": "Number", "title": "Номер", "valueType": "String", "length": 11 }, { "name": "Контрагент", "valueType": "CatalogRef.Контрагенты" }],
      "tabularSections": [{ "name": "Товары", "columns": [{ "name": "Номенклатура", "valueType": "CatalogRef.Номенклатура" }] }]
    }
  } }
```

| Свойство | Русское | Значение |
| --- | --- | --- |
| `name` | Имя | имя реквизита, колонки, реквизита типа; стандартные реквизиты - английским именем, как в пути к данным EDT (`Number`, `Description`, `Ref`) |
| `title` | Заголовок | не указан - имя по словам |
| `valueType` | Тип | имя типа платформы, как в EDT: `String`, `Number`, `Date`, `Boolean`, `CatalogRef.Имя`, `DocumentObject.Имя`, `ValueTable`, `ValueTree`, `ValueList`, `DynamicList`; составной тип - списком |
| `length`, `digits`, `fractionDigits` | Длина, Разрядность, Разрядность дробной части | квалификаторы типа, как у поля ввода |
| `main` | Основной реквизит | `true` - основной реквизит формы; *в 1С не напрямую* |
| `mainTable` | Основная таблица | у динамического списка: `Catalog.Имя` |
| `columns` | Колонки | у таблицы и дерева значений - реквизиты строки |
| `additionalColumns` | Дополнительные колонки | у реквизита формы: колонки, добавленные формой к табличной части, - путь от реквизита (`Товары`) → колонки |
| `tabularSections` | Табличные части | в `types`: табличные части объекта, у каждой `columns` |

Ключ `types` - полное имя объекта метаданных (`Catalog.Контрагенты`): типы `CatalogRef.Контрагенты` и
`CatalogObject.Контрагенты` раскрываются одним описанием. Перечисления не описываются.

Импорт заполняет `attributes` из реквизитов формы (EDT `Form.form`, выгрузка `Form.xml`), `types` - из
метаданных, если исходники конфигурации рядом: объекты реквизитов формы (основной реквизит), основные таблицы
динамических списков и типы по путям элементов (`Объект.Контрагент.ИНН` - описан `Catalog.Контрагенты`).
Остальные ссылки - листья дерева: путь через них набирается строкой, тип описывается в окне выбора. Без
исходников - только реквизиты формы.

Где какой путь допустим (опыт в EDT и корпуса типовых конфигураций):

| Место | Путь | Глубина по ссылке |
| --- | --- | --- |
| поле вне таблицы | реквизит формы, реквизит объекта, колонка коллекции (значение текущей строки) | не ограничена |
| колонка таблицы | только внутри пути своей таблицы: колонка, реквизит колонки по ссылке | не ограничена |
| колонка динамического списка | поле списка, его реквизиты по ссылке | не ограничена |
| таблица | коллекция: табличная часть объекта, таблица и дерево значений, список значений, динамический список | коллекция через ссылку - не в дереве выбора |

## Панель свойств конструктора

Конструктор (`formmockup.py serve`) показывает все свойства вида
по этой схеме группами палитры конфигуратора: «Основные», «Использование», «Оформление»,
«Расположение» и «Макет» - свойства примечания и примера (`note`, `sample`, у формы `formKind`).
Группы, блоки и порядок - `property-groups.json` (по снимкам палитры свойств конфигуратора), там же
умолчания платформы для незаданных свойств (`defaults`, по таблицам этого справочника) и
свойства, которые панель не правит (`locked`: `renamedFrom`, `sourceType`), и применимость по месту
(`places`, по оговоркам справочника синтаксиса 1С: свойства колонки - только у колонки таблицы, положение в
командной панели - у кнопки панели; пустой список - у вида в 1С такого свойства нет). Модель и схему файл не
меняет. Новое свойство схемы вносится и в группы своего вида тем же изменением: тест
`test_server.PropertyGroupsTest` следит, чтобы у каждого вида каждое свойство было в группе.

Названия в панели: у свойства платформы - слитно, как в палитре («ПоложениеЗаголовка»), у
свойства из реестра `x-platform` - как в словаре («Тип значения»). Значение, равное умолчанию,
конструктор в модель не пишет; переименование элемента из файла ставит `renamedFrom`.

## Проверка `check`

`formmockup.py check model.json` - код 0, если замечаний нет, 1 - есть, 2 - файл не читается
или не JSON. Строка замечания: `<имена по пути> (<путь в JSON>): <текст> [<правило>]`.

| Правило | Что ловит |
| --- | --- |
| `schema` | нарушение схемы: тип, значение не из списка, нет `type` или `name`, имя не по правилам 1С, вид не на своём месте (`Page` вне `Pages`), неизвестное свойство |
| `foreign-property` | свойство другого вида: `checkBoxType` у `InputField` |
| `duplicate-name` | `name` уже занято другим элементом |
| `empty-container` | пустая группа, закладка, группа колонок, группа кнопок, подменю; панель закладок без закладок |
| `single-page` | одна закладка в панели |
| `table-no-columns` | таблица без колонок |
| `current-page` | `currentPage` называет закладку, которой нет в панели |
| `too-many-items` | больше 25 видимых элементов на закладке или в форме вне закладок; группы, командные панели и колонки таблицы не считаются |
| `group-depth` | больше 4 обычных групп, вложенных друг в друга |
| `style-color` | цвет `style:<Имя>`, значения которого нет в `styles`: макет рисует элемент без цвета |
| `data-path` | при заданных `attributes`: путь к данным элемента не проходится по `attributes` и `types` (реквизита нет), колонка таблицы с путем вне пути своей таблицы. Путь через неописанный тип, динамический список и стандартные реквизиты (английские имена) не проверяется. Без `attributes` правило молчит |
