# Целостность MDO-файлов (EDT)

Правила поддержания согласованности MDO-файлов конфигурации 1С в формате EDT.

---

## UUID — уникальность обязательна

Каждый UUID в атрибутах `uuid`, `typeId`, `valueTypeId` должен быть **глобально уникальным** по всем MDO-файлам проекта.

**Запрещено:**
- Копировать UUID между MDO-файлами
- Использовать последовательные или placeholder UUID при генерации метаданных

**Способ генерации:** каждый UUID генерировать отдельно:
- Python: `uuid.uuid4()`
- PowerShell: `[guid]::NewGuid()`

---

## Ссылки на объекты метаданных

Перед добавлением ссылок на объекты в:
- Exchange plans (`<content><mdObject>`)
- Subsystems (`<content>`)
- Event subscriptions
- Defined types

**Проверить, что объект существует** в конфигурации.

**Типичные ошибки:**
- Ссылки на объекты из другой версии конфигурации
- Ссылки на несуществующие объекты
- Опечатки в именах объектов

**Последствия битых ссылок:** платформа выдаёт ошибку при загрузке — несоответствие типов в `Content.xml`.

---

## Стандартные атрибуты табличных частей

Блок `<standardAttributes><name>LineNumber</name>...</standardAttributes>` в MDO-файлах табличных частей **не добавлять** — платформа добавляет его автоматически.
---

## `Form.form`, написанный руками: значения перечислений сверять с соседними формами

EDT принимает в `Form.form` значения перечислений шире, чем конфигуратор: валидация проекта
чистая, а падает загрузка в ИБ — с ошибкой уровня XML, без указания элемента формы:

```text
Ошибка загрузки/выгрузки конфигурации
по причине:
Исключение XDTO произошло при чтении файла- zip:///DataProcessors/<Объект>/Forms/<Форма>/Ext/Form.xml
по причине:
Несоответствие свойства и элемента данных XDTO:
Свойство: 'Group'
```

Известный случай: корневое `<group>` формы (группировка подчинённых элементов) — конфигуратор
принимает `Vertical`, но не `Auto`, хотя `Auto` допустим у `behavior`, `throughAlign`,
`currentRowUse` внутри `UsualGroupExtInfo` и потому легко попадает в файл по аналогии.

**Перед обновлением ИБ** — сверить значения с формами, сделанными дизайнером; отклонение видно
сразу:

```bash
grep -rn "^  <group>" --include=Form.form src | awk -F: '{print $3}' | sort | uniq -c
```

Имя свойства из текста ошибки (`Group`) — это имя из XDTO-пакета конфигуратора, а не тег
`.form`: искать по смыслу, а не подстрокой.
