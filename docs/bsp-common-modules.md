# Общие модули БСП — справочник

Краткий справочник по публичному API общих модулей БСП, которые чаще всего используются в PrintWizard. Цель — не заставлять Claude (и человека) писать вручную то, что уже есть в БСП. Полные описания методов — в исходниках БСП в хост-проекте `pw_macos`:

- `/Users/a1/Documents/1C/03 EDT projects/pw_macos/PrintWizard/src/CommonModules/<Имя>/Module.bsl`

В справочник включены **только публичные методы** (`#Область ПрограммныйИнтерфейс`). Устаревшие (`УстаревшиеПроцедурыИФункции`) и служебные (`СлужебныйПрограммныйИнтерфейс`, `СлужебныеПроцедурыИФункции`) намеренно исключены — расширению пользоваться ими нельзя.

> **Не путать с проектными модулями `pw_*`.** В PrintWizard есть собственные общие модули с похожими именами — например, `pw_ОбщегоНазначения`, `pw_ОбщегоНазначенияКлиентСервер`. Это **другие** модули с проектными хелперами (см. memory `project_pw_obshego_nazn_helpers`). Когда видите вызов вида `ОбщегоНазначения*.Метод(...)` без префикса `pw_` — это БСП из этого справочника. С префиксом `pw_` — проектный модуль, описание ищется в исходниках расширения, не здесь. Аналогично для `Пользователи` vs `pw_Пользователи*` и т.п.

## Какой модуль брать в каком контексте

| Контекст вызывающего кода | Подходящий суффикс модуля |
| --- | --- |
| Серверная процедура / `&НаСервере` / `&НаСервереБезКонтекста` | `ОбщегоНазначения`, `СтроковыеФункции`, `Пользователи`, `ФайловаяСистема` |
| Клиентская процедура (`&НаКлиенте`, без серверного контекста) | `ОбщегоНазначенияКлиент`, `СтроковыеФункцииКлиент`, `ПользователиКлиент`, `ФайловаяСистемаКлиент` |
| Клиент-серверный модуль или процедура без `&НаКлиенте/&НаСервере` | `ОбщегоНазначенияКлиентСервер`, `СтроковыеФункцииКлиентСервер`, `ПользователиКлиентСервер` |
| Прямой серверный вызов из клиентского контекста (без оборачивания в собственный серверный модуль) | `ОбщегоНазначенияВызовСервера` |
| Локализованные функции для русского языка | `СтроковыеФункцииКлиентСерверРФ` |

> **Правило выбора:** если метод нужен и на клиенте, и на сервере — берём `*КлиентСервер`. Если только на одной стороне — соответствующий модуль. Не дублировать клиент-серверную логику в двух местах.

## ОбщегоНазначения / *Клиент / *КлиентСервер / *ВызовСервера

### Сообщения пользователю

| Метод | Модуль |
| --- | --- |
| `СообщитьПользователю(...)` | `ОбщегоНазначения`, `ОбщегоНазначенияКлиент` |
| `ДобавитьОшибкуПользователю(...)` | `ОбщегоНазначенияКлиентСервер` |
| `СообщитьОшибкиПользователю(Ошибки, Отказ = Ложь)` | `ОбщегоНазначенияКлиентСервер` |
| `ТекстОшибкиЗаполнения(...)` | `ОбщегоНазначенияКлиентСервер` |
| `ПутьКТабличнойЧасти(...)` | `ОбщегоНазначенияКлиентСервер` |

Платформенный `Сообщить()` использовать **запрещено** — только `СообщитьПользователю`.

### Чтение реквизитов объектов

| Метод | Назначение |
| --- | --- |
| `ЗначениеРеквизитаОбъекта(Ссылка, ИмяРеквизита, ВыбратьРазрешенные = Ложь, КодЯзыка = Неопределено)` | Один реквизит одного объекта |
| `ЗначенияРеквизитовОбъекта(Ссылка, Реквизиты, ...)` | Несколько реквизитов одного объекта (`Реквизиты` = строка через запятую или структура) |
| `ЗначениеРеквизитаОбъектов(МассивСсылок, ИмяРеквизита, ...)` | Один реквизит для многих объектов |
| `ЗначенияРеквизитовОбъектов(Ссылки, Реквизиты, ...)` | Несколько реквизитов для многих объектов |

Все — только в серверном `ОбщегоНазначения`.

> **Антипаттерн:** `Ссылка.Реквизит` — критический. Любое обращение к реквизиту через точку — через эти методы.

## Что использовать запрещено

- Методы из `#Область УстаревшиеПроцедурыИФункции` — БСП помечает их к удалению.
- Методы из `#Область СлужебныйПрограммныйИнтерфейс` — для подсистем БСП, не для расширений.
- Модули с суффиксами `*Служебный`, `*ПовтИсп`, `*Переопределяемый` — внутренняя кухня БСП.
- Модули с суффиксом `*БТС` — это библиотека технологии сервиса (БТС), отдельная подсистема, не базовый набор БСП.
