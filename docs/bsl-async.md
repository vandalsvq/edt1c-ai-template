# Асинхронные методы 1С (Асинх / Ждать / Обещание)

Правила использования механизма асинхронности (платформа 8.3.18+).

Применяется: при написании клиентского кода с асинхронными вызовами.

---

## Основные принципы

1. Все новые асинхронные функции (суффикс `Асинх`) возвращают `Обещание`
2. `Ждать` — оператор ожидания завершения `Обещание`
3. `*Асинх`-методы вызывать **только внутри** процедур/функций с ключевым словом `Асинх`
4. `Обещание` имеет 3 состояния: **Ожидание**, **Успех**, **Провал**
5. Работает только **на клиенте** (`&НаКлиенте`)

---

## Соответствие старых и новых методов

Предпочитать новый синтаксис `*Асинх` вместо `Показать*` с `ОписаниеОповещения`:

| Модальный (запрещён) | Через оповещение | Новый Асинх |
|---|---|---|
| `Предупреждение()` | `ПоказатьПредупреждение()` | `ПредупреждениеАсинх()` |
| `Вопрос()` | `ПоказатьВопрос()` | `ВопросАсинх()` |
| `ОткрытьЗначение()` | `ПоказатьЗначение()` | `ОткрытьЗначениеАсинх()` |
| `ВвестиЧисло()` | `ПоказатьВводЧисла()` | `ВвестиЧислоАсинх()` |
| `НайтиФайлы()` | `НачатьПоискФайлов()` | `НайтиФайлыАсинх()` |
| `ПоместитьФайлы()` | `НачатьПомещениеФайлов()` | `ПоместитьФайлыНаСерверАсинх()` |

### Исключение: предупреждение без ожидания ответа

Если результат диалога не нужен (предупреждение «к сведению», после которого ничего не происходит) — не заворачивать его в `Асинх`/`Ждать`. Достаточно `ПоказатьПредупреждение` **без** обработчика оповещения: метод выводит окно и не ожидает закрытия (fire-and-forget).

```bsl
// Достаточно — ответ не нужен, обработчик не указываем:
ПоказатьПредупреждение(, НСтр("ru = 'Документ проведён.'"));

// Избыточно — ПредупреждениеАсинх требует Асинх-процедуру и Ждать ради Неопределено:
Ждать ПредупреждениеАсинх(НСтр("ru = 'Документ проведён.'"));
```

`ПредупреждениеАсинх` (с `Ждать`) оправдан только когда после закрытия окна должен продолжиться код в той же процедуре. `Вопрос`/`ВвестиЧисло` и подобные — всегда через `*Асинх`, т.к. результат диалога значим.

---

## Возвращаемые значения

| Метод | Результат `Ждать` |
|---|---|
| `ПредупреждениеАсинх` | `Неопределено` |
| `ВопросАсинх` | `КодВозвратаДиалога` |
| `ОткрытьЗначениеАсинх` | `Неопределено` |
| `ВвестиЧислоАсинх` | `Число` |
| `НайтиФайлыАсинх` | `Массив` объектов типа `Файл` |
| `ПоместитьФайлыНаСерверАсинх` | `Массив` из `ОписаниеПомещенногоФайла` (успех) / `Неопределено` (провал) |

## Базовый шаблон

```bsl
&НаКлиенте
Асинх Процедура МояПроцедура()

	Обещание = ВопросАсинх("Продолжить?", РежимДиалогаВопрос.ДаНет);
	Результат = Ждать Обещание;

	Если Результат = КодВозвратаДиалога.Да Тогда
		// Действие
	КонецЕсли;

КонецПроцедуры
```

## Критические правила

### 1. Без `Ждать` исключения теряются молча

Если вызвать асинхронную функцию без `Ждать` и внутри возникнет исключение — оно **проглочено без следа**:

```bsl
// ОПАСНО: исключение внутри ВызватьОшибку() будет потеряно
Процедура МояПроцедура(Команда)
	ВызватьОшибку(); // Асинх-функция вызвана без Ждать
КонецПроцедуры

Асинх Функция ВызватьОшибку()
	ВызватьИсключение "ошибка!"; // никто не увидит
КонецФункции
```

**Правило:** Всегда использовать `Ждать` при вызове `Асинх`-функций, если важен результат или обработка ошибок.
Без `Ждать` — только для fire-and-forget, когда ошибки осознанно игнорируются.

### 2. Обработчики событий формы нельзя делать `Асинх`

Обработчики `ПриОткрытии`, `ПередЗакрытием` и т.д. с ключевым словом `Асинх` **не работают** — платформа не ждёт их завершения:

```bsl
// НЕ РАБОТАЕТ: Отказ = Истина будет проигнорирован
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)
	Отказ = Истина;             // платформа уже продолжила выполнение
	ВызватьИсключение "ошибка"; // пользователь увидит ошибку, но форма уже открыта
КонецПроцедуры
```

**Правило:** НЕ делать обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`, `ПриЗаписиНаСервере` и т.д.) асинхронными. Вместо этого — вызывать отдельную `Асинх`-процедуру из обычного обработчика.

### 3. Обработчики команд — можно делать `Асинх`

```bsl
&НаКлиенте
Асинх Процедура МояКоманда(Команда)
	Обещание = ВвестиЧислоАсинх(1, "Укажите число");
	Результат = Ждать Обещание;
КонецПроцедуры
```

## Паттерн: Вопрос при открытии формы

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	ЗадатьВопросПриОткрытии();
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриОткрытии()
	Обещание = ВопросАсинх(
		"Продолжить работу?",
		РежимДиалогаВопрос.ДаНет, ,
		КодВозвратаДиалога.Да);
	Результат = Ждать Обещание;

	Если Результат <> КодВозвратаДиалога.Да Тогда
		ЭтотОбъект.Закрыть();
	КонецЕсли;
КонецПроцедуры
```

---

## Паттерн: Вопрос при закрытии формы

Используется переменная-флаг для предотвращения рекурсии:

```bsl
&НаКлиенте
Перем ВопросПриЗакрытииЗадан;

&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы,
		ТекстПредупреждения, СтандартнаяОбработка)
	Если НЕ ВопросПриЗакрытииЗадан Тогда
		ЗадатьВопросПриЗакрытии();
		Отказ = Истина;
	КонецЕсли;
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриЗакрытии()
	Обещание = ВопросАсинх(
		"Закрыть форму?",
		РежимДиалогаВопрос.ДаНет, ,
		КодВозвратаДиалога.Да);
	Результат = Ждать Обещание;

	Если Результат = КодВозвратаДиалога.Да Тогда
		ВопросПриЗакрытииЗадан = Истина;
		ЭтотОбъект.Закрыть();
	КонецЕсли;
КонецПроцедуры

// Инициализация в теле модуля:
ВопросПриЗакрытииЗадан = Ложь;
```

## Паттерн: Работа с файлами

```bsl
&НаКлиенте
Асинх Процедура ЗагрузитьФайлыНаСервер()

	// 1. Найти файлы
	Обещание        = НайтиФайлыАсинх(ПутьКПапке, "*.*", Ложь);
	НайденныеФайлы  = Ждать Обещание;

	// 2. Подготовить описания
	ДобавляемыеФайлы = Новый Массив;
	Для Каждого НайденныйФайл Из НайденныеФайлы Цикл
		Описание      = Новый ОписаниеПередаваемогоФайла;
		Описание.Имя  = НайденныйФайл.ПолноеИмя;
		ДобавляемыеФайлы.Добавить(Описание);
	КонецЦикла;

	// 3. Поместить на сервер
	Обещание = ПоместитьФайлыНаСерверАсинх(
		, , ДобавляемыеФайлы, ЭтотОбъект.УникальныйИдентификатор);
	Результат = Ждать Обещание;

КонецПроцедуры
```
