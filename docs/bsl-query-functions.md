# Функции и выражения языка запросов 1С

Полный справочник функций, доступных в языке запросов 1С.

---

## ВЫРАЗИТЬ — приведение типов

Явно приводит значение к конкретному типу. **Обязательно для полей составного типа.**

```sql
ВЫРАЗИТЬ(<выражение> КАК <тип>)
```

```sql
// Сужение составной ссылки до конкретного типа:
ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваровУслуг)

// Приведение числа к точности:
ВЫРАЗИТЬ(Сумма КАК ЧИСЛО(15, 2))

// Приведение к строке:
ВЫРАЗИТЬ(Код КАК СТРОКА(10))

// Приведение к булево:
ВЫРАЗИТЬ(Значение КАК БУЛЕВО)

// Приведение к дате:
ВЫРАЗИТЬ(Значение КАК ДАТА)
```

Примитивные типы для приведения: `ЧИСЛО(<длина>, <точность>)`, `СТРОКА(<длина>)`, `БУЛЕВО`, `ДАТА`.

---

## Агрегатные функции

Используются с `СГРУППИРОВАТЬ ПО`, `ИМЕЮЩИЕ`, `ИТОГИ`, `УПОРЯДОЧИТЬ ПО`.

| Функция | Описание | Пример |
|---------|----------|--------|
| `СУММА(<поле>)` | Сумма | `СУММА(Количество)` |
| `СРЕДНЕЕ(<поле>)` | Среднее значение | `СРЕДНЕЕ(Цена)` |
| `МИНИМУМ(<поле>)` | Минимальное значение | `МИНИМУМ(Дата)` |
| `МАКСИМУМ(<поле>)` | Максимальное значение | `МАКСИМУМ(Дата)` |
| `КОЛИЧЕСТВО(*)` | Количество всех строк | `КОЛИЧЕСТВО(*)` |
| `КОЛИЧЕСТВО(<поле>)` | Количество не-NULL значений | `КОЛИЧЕСТВО(Контрагент)` |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ <поле>)` | Количество уникальных значений | `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Контрагент)` |

Поля группировки не использовать внутри агрегатных функций.

## Функции даты

### Извлечение компонентов

| Функция | Возвращает | Пример |
|---------|------------|--------|
| `ГОД(<дата>)` | Год | `ГОД(Дата)` → 2024 |
| `КВАРТАЛ(<дата>)` | Квартал (1–4) | `КВАРТАЛ(Дата)` → 1 |
| `МЕСЯЦ(<дата>)` | Месяц (1–12) | `МЕСЯЦ(Дата)` → 3 |
| `ДЕНЬГОДА(<дата>)` | День года (1–366) | `ДЕНЬГОДА(Дата)` |
| `ДЕНЬ(<дата>)` | День месяца (1–31) | `ДЕНЬ(Дата)` → 15 |
| `ДЕНЬНЕДЕЛИ(<дата>)` | День недели (1=пн..7=вс) | `ДЕНЬНЕДЕЛИ(Дата)` |
| `ЧАС(<дата>)` | Час (0–23) | `ЧАС(Дата)` |
| `МИНУТА(<дата>)` | Минута (0–59) | `МИНУТА(Дата)` |
| `СЕКУНДА(<дата>)` | Секунда (0–59) | `СЕКУНДА(Дата)` |

### Границы периодов

| Функция | Описание |
|---------|----------|
| `НАЧАЛОПЕРИОДА(<дата>, <период>)` | Начало периода. `<период>`: МИНУТА, ЧАС, ДЕНЬ, НЕДЕЛЯ, МЕСЯЦ, КВАРТАЛ, ГОД, ДЕКАДА, ПОЛУГОДИЕ |
| `КОНЕЦПЕРИОДА(<дата>, <период>)` | Конец периода (те же варианты) |

```sql
НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ)      // первый день месяца
КОНЕЦПЕРИОДА(Дата, КВАРТАЛ)     // последний момент квартала
```

### Арифметика дат

| Функция | Описание |
|---------|----------|
| `ДОБАВИТЬКДАТЕ(<дата>, <период>, <количество>)` | Добавить N периодов к дате |
| `РАЗНОСТЬДАТ(<дата1>, <дата2>, <период>)` | Разность между датами в периодах |

```sql
ДОБАВИТЬКДАТЕ(Дата, МЕСЯЦ, 3)          // добавить 3 месяца
ДОБАВИТЬКДАТЕ(Дата, ДЕНЬ, -7)           // вычесть 7 дней
РАЗНОСТЬДАТ(ДатаНач, ДатаКон, ДЕНЬ)    // дней между датами
```

Варианты периода: `СЕКУНДА`, `МИНУТА`, `ЧАС`, `ДЕНЬ`, `МЕСЯЦ`, `КВАРТАЛ`, `ГОД`.

## Строковые функции

| Функция | Описание | Пример |
|---------|----------|--------|
| `ПОДСТРОКА(<стр>, <начало>, <длина>)` | Подстрока (нумерация с 1) | `ПОДСТРОКА(Код, 1, 3)` |
| `ДЛИНАСТРОКИ(<стр>)` | Длина строки | `ДЛИНАСТРОКИ(Наименование)` |
| `ЛЕВ(<стр>, <n>)` | Первые N символов | `ЛЕВ(Код, 5)` |
| `ПРАВ(<стр>, <n>)` | Последние N символов | `ПРАВ(Код, 3)` |
| `СТРЗАМЕНИТЬ(<стр>, <найти>, <заменить>)` | Заменить подстроку | `СТРЗАМЕНИТЬ(Имя, " ", "_")` |
| `СОКРЛ(<стр>)` | Обрезать пробелы слева | `СОКРЛ(Код)` |
| `СОКРП(<стр>)` | Обрезать пробелы справа | `СОКРП(Код)` |
| `СОКРЛП(<стр>)` | Обрезать пробелы с обеих сторон | `СОКРЛП(Код)` |
| `ВРЕГ(<стр>)` | Верхний регистр | `ВРЕГ(Наименование)` |
| `НРЕГ(<стр>)` | Нижний регистр | `НРЕГ(Наименование)` |

**Важно:** `ПОДСТРОКА` в основном условии ГДЕ запрещает использование индекса. Использовать только в дополнительных условиях.

## Функции типов

| Функция | Описание | Пример |
|---------|----------|--------|
| `ТИПЗНАЧЕНИЯ(<выражение>)` | Возвращает тип значения | `ТИПЗНАЧЕНИЯ(Ссылка)` |
| `ТИП(<имя_типа>)` | Возвращает объект типа для сравнения | `ТИП("Справочник.Контрагенты")` |
| `ССЫЛКА` | Оператор проверки типа ссылки | `Рег ССЫЛКА Документ.Реализация` |
| `ПРЕДСТАВЛЕНИЕ(<выражение>)` | Строковое представление ссылки | `ПРЕДСТАВЛЕНИЕ(Контрагент)` |
| `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(<ссылка>)` | UUID ссылки в виде строки | `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Ссылка)` |

```sql
// Фильтр по типу значения:
ГДЕ ТИПЗНАЧЕНИЯ(Субконто1) = ТИП("Справочник.Контрагенты")
```

## Логические функции и NULL

| Функция | Описание |
|---------|----------|
| `ЕСТЬNULL(<выражение>, <значение_по_умолчанию>)` | Возвращает второй аргумент, если первый NULL (аналог COALESCE для двух аргументов) |

```sql
ЕСТЬNULL(Ост.КоличествоОстаток, 0)
```

**ВЫБОР (CASE):**

```sql
ВЫБОР
    КОГДА <условие1> ТОГДА <результат1>
    КОГДА <условие2> ТОГДА <результат2>
    ИНАЧЕ <результат_по_умолчанию>
КОНЕЦ
```

Можно использовать в списке полей, ИМЕЮЩИЕ, ИТОГИ. **Нельзя** использовать в основном (индексируемом) условии ГДЕ.

## Математические функции

| Функция | Описание |
|---------|----------|
| `ОКР(<число>, <точность>)` | Округление до N знаков после запятой |
| `ЦЕЛ(<число>)` | Целая часть (усечение к нулю) |

```sql
ОКР(Сумма / Количество, 2)   // округлить до 2 знаков
ЦЕЛ(Сумма / 100)             // целая часть
```

## Арифметические операторы

`+`, `-`, `*`, `/` — стандартная арифметика. Точность — не менее 8 знаков после запятой.

**В ГДЕ:** использовать только в дополнительных условиях (запрещает использование индекса в основном условии).

---

## Константы и литералы

| Тип | Синтаксис | Пример |
|-----|-----------|--------|
| Булево | `ИСТИНА` / `ЛОЖЬ` | `ГДЕ Проведен = ИСТИНА` |
| Число | Десятичный литерал | `1000`, `3.14` |
| Строка | Двойные кавычки | `"Текст"` |
| Строка с кавычками | Удвоение `"` | `"Компания ""Рога и Копыта"""` |
| Дата | `ДАТАВРЕМЯ(<Г>, <М>, <Д> [, <Ч>, <Мин>, <С>])` | `ДАТАВРЕМЯ(2024, 1, 15)` |
| NULL | `NULL` | `ЕСТЬNULL(X, 0)` |
| Неопределено | `НЕОПРЕДЕЛЕНО` | |
| Значение перечисления | `ЗНАЧЕНИЕ(...)` | `ЗНАЧЕНИЕ(Перечисление.Типы.Оптовая)` |
| Пустая ссылка | `ЗНАЧЕНИЕ(Справочник.X.ПустаяСсылка)` | |

**Параметры:** `&Имя` — внешние значения, передаваемые в запрос. Всегда предпочитать параметры конкатенации строк.
